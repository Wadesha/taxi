这个项目在做什么？

一句话：出租车顶上的 GPS 盒子每秒记下一条"我在哪、几点、开多快"， 日积月累就是海量轨迹；本项目把三座城市、三个年代的这类数据拿来做可视化与分析。 下图是整个数据流，也是本项目的骨架——每一格都对应一个页面：

数据流：卫星定位 → 记录成文件 → 清洗 → 分析 → 可视化。每一步在本站都有对应页面解释「是什么、为什么、怎么做」。

三个数据集，三个时代

三座城市、三个年份、三种侧重。它们不重叠，正好互补：

北京 · T-Drive 2008

微软研究院发布的经典学术数据集。车多（一万多辆）、覆盖一周， 是轨迹挖掘领域的"标准考题"，几乎所有经典算法都在这上面跑过。

了解北京数据 →

深圳 · 2014

单日 24 小时、约 4700 万条记录的"巨无霸"。多了一个关键字段 passenger——能区分空车巡游和载客运营， 这是北京数据没有的。

了解深圳数据 →

无锡 · 2020

三城里唯一带惯性传感器信号的数据：方向、速度、三轴加速度、 横摆角速度。能分析"这辆车开得稳不稳、有没有急加速"，是行为研究的富矿。

了解无锡数据 →

分析体系一览

一个完整的轨迹分析应该覆盖"空间-时间-行为"三个维度。下表左侧是分析任务， 右侧是本站对应页面；模拟 标记表示该分析尚未用真实全量数据完成，先用演示数据说明方法。

分析任务要回答的问题主要方法状态
轨迹形态与空间分布车开过哪些路？覆盖了城市的哪些区域？轨迹线图、散点、hexbin 热力图真实数据
热点区域识别哪里是热门上客/下客点？密度聚类（DBSCAN）、核密度估计模拟演示
OD 出行矩阵人们主要从哪个区去哪个区？起讫点提取、矩阵热力图模拟演示
速度画像车速分布长什么样？哪些时段堵？速度直方图、分时段统计真实数据
跨城综合对比三座城市的数据/行为有何差异？多图并置、参数对照表真实数据

仓库结构（怎么组织）

项目文件夹按"概念 → 数据 → 分析 → 方法"四层组织，原始大数据单独收在 raw/（不会进入 git），网站只引用样本和图表：

taxi/
├── index.html                # 本页：总览 + 学习路径
├── guide/                    # 📖 基础概念（GPS、轨迹格式）
├── datasets/                 # 🗂️ 三个数据集详情 + simulation.html（模拟图鉴）
├── analysis/                 # 🔬 分析方法与结果（含模拟演示）
├── methodology/              # 🛠️ 数据管线 + 部署指南
├── assets/
│   ├── css/ style.css
│   ├── js/   main.js
│   └── img/  分析图（真实+模拟）
├── data/
│   ├── 每城 50 行样本 + summary.json
│   └── sim/  12 个模拟数据集 CSV + manifest.json
├── scripts/                  # Python 脚本（可复现）
├── raw/                      # ⚠️ 原始大数据（已迁归档仓库，git 忽略）
└── docs/                     # 数据说明文档
