从原始文件到可看的图：完整管线

一份出租车轨迹数据在能被分析之前，要经历"解压 → 解析 → 清洗 → 分析 → 可视化"五个阶段。 本项目的静态站和图表全部依赖 Python + pandas + matplotlib 完成，没有复杂框架，便于复现。

五阶段管线

出租车轨迹数据处理五阶段：解压 → 解析 → 清洗 → 分析 → 可视化。

阶段 1：解压原始文件

三城原始文件的归档方式不同：

城市原始格式解压后结构
北京.rar（单个压缩包）Beijing(...)/T-Drive trajectory data sample/1.txt ...
深圳.zip（含 24 个 CSV）00_时.csv ... 23_时.csv
无锡.zip（含多日 CSV）20200718.csv ...

解压示例（Python）：

# 深圳：解压 2014_10_22.zip
import zipfile, os
with zipfile.ZipFile(r"raw/shenzhen/2014_10_22.zip", 'r') as z:
    z.extractall(r"raw/shenzhen/")

# 北京：用 7-Zip 命令行解压 RAR
# 7z x "raw/beijing/2.T_drive 轨迹数据.rar" -oraw/beijing/

阶段 2：解析——三城三个"小脾气"

北京：无表头，四字段纯数字

import pandas as pd
p = r"raw/beijing/.../T-Drive trajectory data sample/1.txt"
df = pd.read_csv(p, header=None, names=['taxi_id','ts','lon','lat'])

深圳：有表头，标准 CSV

p = r"raw/shenzhen/12_时.csv"
df = pd.read_csv(p, nrows=400000)  # 大文件可采样
# 字段：trajectory_id, date, lon, lat, passenger, speed(km/h)

无锡：表头正常，但每行 id 后带隐藏制表符

无锡文件每行的格式是 id\t,lon,lat,...：id 和第一个逗号之间藏了一个制表符。直接用 pandas 读会把它吞进 id 字段，必须手动清理：

p = r"raw/wuxi/data/20200718.csv"
recs = []
with open(p, 'r', encoding='utf-8', errors='replace') as f:
    for i, line in enumerate(f):
        line = line.rstrip('\r\n')
        if i == 0: continue
        cells = line.split(',')
        cells[0] = cells[0].strip()   # 去掉 id 后的 \t
        recs.append(cells)

cols = ['id','经度','纬度','采集时间','方向','速度',
        '纵向加速度','横向加速度','垂直加速度','横摆角速度']
df = pd.DataFrame(recs, columns=cols)
⚠️
解析阶段的常见坑： ① 北京没有时间列，需要自己解析字符串成 datetime； ② 深圳 date 只有时分秒，必须结合文件名补真实日期； ③ 无锡 id 列带隐藏制表符，不清洗会污染后续去重/分组。

阶段 3：清洗——让数据可信

清洗不是"删掉不合心意的数"，而是给数据划定可信边界。本项目常用的三条：

清洗项规则示例目的
边界裁剪深圳 lon∈[113.7,114.7], lat∈[22.3,23.0]去掉邻近城市漂移点
速度截尾删除 speed>120 km/h过滤 GPS 跳变和高速异常
去重df.drop_duplicates(subset=['lon','lat'])去掉 GPS 漂移导致的重复记录
排序按 vehicle_id + timestamp 排序保证轨迹连续

示例：

# 深圳清洗
shenzhen_clean = df[
    df['lon'].between(113.7, 114.7) &
    df['lat'].between(22.3, 23.0) &
    (df['speed(km/h)'] <= 120)
].drop_duplicates(subset=['trajectory_id','lon','lat','date'])

阶段 4：分析——三个核心方法

清洗后的数据通常按"车辆 → 时间排序"组织。在此基础上：

停留点检测

速度≈0 且持续时间>阈值 → 一个停留点。把连续移动段切分成 O-D 对。

速度画像

分箱统计速度分布；按小时/路段聚合，识别高峰拥堵时段。

热点聚类

把停留点堆叠，用 DBSCAN / KDE 找出高密度区，即为空间热点。

阶段 5：可视化——matplotlib 出图

本项目所有图表用 matplotlib 的 Agg 后端生成 PNG，再嵌入静态 HTML：

import matplotlib
matplotlib.use('Agg')      # 无头环境出图
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(10, 8))
ax.scatter(df['lon'], df['lat'], s=2, alpha=0.4)
ax.set_xlabel('经度'); ax.set_ylabel('纬度')
fig.savefig('assets/img/example.png', dpi=150, bbox_inches='tight')
📌
为什么选 matplotlib 而不是交互地图库？ 因为目标是 GitHub Pages 静态站，没有后端、没有 API key、不依赖在线地图服务。 matplotlib 出 PNG 最稳，任何人 fork 仓库后都能直接复现。
