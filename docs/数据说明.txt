北京出租车轨迹数据集 (T-Drive) 说明
====================================

一、数据集概况
-----------
数据来源：北京出租车GPS轨迹数据集
数据名称：T-Drive Trajectory Data
采样规模：10,357 辆出租车
采样时间：2008年2月，一周数据
原始大小：73 MB (压缩)
解压大小：452 MB
文件数量：8,911 个轨迹文件

二、数据结构
-----------
1. 文件组织
   └── Beijing(one-week trajectories of 10,357 taxis)/
       ├── User_guide_T-drive.pdf  # 用户指南
       └── T-Drive trajectory data sample/
           ├── 1.txt                # 出租车1的轨迹
           ├── 2.txt                # 出租车2的轨迹
           ├── ...
           └── 10202.txt            # 出租车10202的轨迹

2. 数据格式
   每个txt文件代表一辆出租车，包含其GPS轨迹记录
   
   字段说明：
   - 字段1：出租车ID (整数)
   - 字段2：时间戳 (YYYY-MM-DD HH:MM:SS)
   - 字段3：经度 (小数，116.xxxx)
   - 字段4：纬度 (小数，39.xxxx)

3. 样本数据示例：
   1,2008-02-02 15:36:08,116.51172,39.92123
   1,2008-02-02 15:46:08,116.51135,39.93883
   1,2008-02-02 15:56:08,116.51627,39.91034

三、数据特征
-----------
1. 时间特征
   - 记录间隔：约10分钟一次
   - 数据跨度：2008年2月2日 - 2008年2月8日（一周）
   - 工作日数据较多，周末相对较少

2. 空间特征
   - 经度范围：116.4° - 116.7°E
   - 纬度范围：39.8° - 40.0°N
   - 覆盖区域：北京市区及郊区

3. 数据质量
   - 部分出租车记录点数差异较大
   - 存在重复记录（GPS漂移）
   - 部分时间段数据缺失
