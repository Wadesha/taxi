数据是怎么被采集的：从卫星到文件

你看到的每一行 veh_id, ts, lon, lat, speed，背后是一整套硬件与链路的产物。 读懂这条链路，你才会明白：为什么坐标有 5~15 米误差、为什么轨迹会「穿墙」、为什么有的数据只有 OD、为什么隐私脱敏没那么简单。这一页讲「更底层」的东西。

一、一个 GPS 点是怎么出生的

车载终端里有一个 GNSS 模块（GPS / 北斗 / GLONASS / Galileo），它做的事本质很简单：听卫星报时，算自己离卫星多远，三个球面交出一个点。

三边（实际常需第 4 颗解钟差）定位：每颗卫星用「收到时间 − 发射时间」算出距离，距离球面相交处就是你的位置。

所以一行坐标并不是「测」出来的绝对真值，而是解算出来的估计值，天然带误差。下面的四类误差，决定了你数据的底噪：

误差源成因典型量级对数据的影响
大气延迟信号穿过电离层/对流层被放慢几米坐标系统性偏移，晴雨不同
钟差接收机钟与卫星原子钟不同步几米~十几米需用第 4 颗星或差分修正
多径（Multipath）信号经高楼/地面反射后到达1~10 米城市峡谷里轨迹「跳变」「穿墙」的主因
星历/几何精度可见卫星分布不好（HDOP 大）1~5 米高架、隧道口定位质量骤降
📍
为什么轨迹会「穿墙」「飞点」？ 多半是多径 + 城市峡谷 + 直线插值叠加的结果。 北京 T-Drive、无锡数据里的零星离群点，根子就在这。清洗时不能简单「删离群」，要先判断是真实绕行还是定位噪点。

链路上的每一跳都可能改变数据：终端决定采样率、通信丢包、服务端做清洗/加密、落盘格式各异。

三、采样间隔，决定你能做什么分析

很多人忽略：采样间隔不是技术细节，而是分析能力的「天花板」。 1 秒一点和 5 分钟一点，能做的题目天差地别。下面这张表是「拿到数据先问自己」的清单：

采样间隔代表数据能做的分析做不了 / 会失真
1~5 秒出租车 GPS、网约车完整路径、瞬时速度、加减速、急转弯、地图匹配—（几乎全能）
20~60 秒公交 AVL、货车北斗线路运行时间、站间速度、宏观轨迹急加减速、短停被抹平
1~5 分钟高速 ETC、干线北斗城际 OD、通道流量直线插值「穿墙」、城市内路径模糊
5~15 分钟聚合线圈检测器、速度指数断面流量、拥堵指数个体轨迹（根本不存在）
行程级（仅 OD）共享单车、计价器OD 分布、时长距离任何路径/地图匹配
数百米精度、分钟~小时手机信令全人群职住、迁徙具体方式、精确路径
⚠️
别用 5 分钟采样的数据去做「急刹车分析」。 两个相邻点之间发生了什么，数据里是真空。强行插值 = 编造。这一条是无数「分析翻车」的根源。

四、五种定位技术：精度与适用场景

「GPS 点」只是定位的一种。不同技术给出不同精度，也对应不同数据源（详见 家族图鉴）：

技术典型精度适用局限
GNSS 单点（GPS/北斗）5~15 m车载/手持通用城市峡谷、隧道失效
差分 / RTK0.1~1 m高精地图、农机需基准站，成本高
蜂窝基站定位几十~几百 m手机信令、室内外过渡精度随基站密度变
WiFi / 蓝牙指纹数 m~几十 m室内定位依赖指纹库
惯性（IMU）漂移累积隧道/高架短时補位单独用会越漂越远

五、WGS-84 / GCJ-02 / BD-09：坐标偏移是国情

这是国内数据最常见的「坑」：同一物理点，三套坐标系数值不同。天朝规定公开地图须用加密偏移坐标。

84
WGS-84

GPS/北斗原始坐标。开源数据（如本项目北京/深圳/无锡）多为这种。

02
GCJ-02

国测局加密偏移。高德、腾讯地图用此。与 WGS-84 差几十~几百米。

09
BD-09

百度在 GCJ-02 上再偏移一次。百度地图用此。

⚠️
把 WGS-84 的点直接叠到高德底图上，会整体偏出几十米到几百米。 跨源融合前必须先统一坐标系（WGS-84 ⇄ GCJ-02 ⇄ BD-09 有公开转换公式）。更多见 GPS 与经纬度。

六、隐私脱敏：四层级（但别以为 anonymized 就安全）

交通轨迹是高度敏感的个体行为数据。脱敏不是「删掉姓名」就完事，常见四层：

L0 原始
完整坐标+时间+个体 ID。泄露即「知道某人何时在哪」。
L1 假名化
ID → 哈希（如 veh_hash）。人读不出，但同一 ID 仍可重跟踪整条轨迹。
L2 泛化/抑制
坐标网格化（500 m）、时间取整、低频群体抑制。
L3 聚合/合成
只留统计产品（速度指数、网格 OD）或合成数据。个体不可还原。

本项目所有模拟数据集均使用 哈希 ID 纯模拟坐标 无真实个体。

⚠️
「假名化」≠「匿名」。 研究者多次证明：仅靠轨迹的时空唯一性（你每天固定路线），就能从假名数据里重新认出个体。 所以本项目真实数据只在本机/归档仓，对外发布只给样本与聚合结果。

七、把这些连起来看

  • 误差（第一节）解释了你数据里的噪点；
  • 链路（第二节）解释了为什么频率/字段各数据源不同；
  • 采样间隔（第三节）画出了分析的天花板；
  • 定位技术（第四节）决定了精度下限；
  • 坐标偏移（第五节）是跨源融合的必过门槛；
  • 隐私（第六节）决定你能公开到哪一步。
